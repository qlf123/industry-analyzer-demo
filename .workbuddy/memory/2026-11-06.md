## 三端技能/知识点维度一致性核查（用户澄清后）

- 结论：**技能维度贯穿三端同源**（备课资源 skillIds → 课次技能 → 评价 → 证据 → 学生 #skills / 学生能力测评老师评价 / 教师学情 / 管理端教学质量 TR）；**知识点维度贯穿教师端+学生端**（挂在技能下、由技能带出，教师学情 kpModel = 学生任务详情 = 学生 #kps，均为最近一次老师确认评价含退回，TK.itemKps）；**管理端无知识点维度**（知识点不进证据、不汇总能力，止步于学情/补训，设计如此）。
