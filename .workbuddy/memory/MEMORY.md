## 达成率双口径（用户 2026-11-18 定，覆盖上一条第 3 点）
- 教师端「技能达成率」= 达成人数 /（**已评价技能数** × 班级人数）：学习效果是学生层面成果，未教/未评价技能不计入分母；已评价技能中未提交、退回未重交的学生**按未达成计**（2026-11-18 下午算法落地对齐）；无任何已评价数据显示「—」（不做「样本不足<2 项」护栏，用户 2026-11-18 明确去掉）
- 「过程口径」= 达成/(已评价的「学生×技能」人次)，仅在学情页脚注展示，不叫「技能达成率」；学生分档「学生达到什么程度」为学期视角（未教计入分母），副标题带口径说明
- 管理端（数据概览/教学质量）保留「标准达成率」= 达成人数 /（课程标准技能数 × 班级人数），未教计入分母，学期末考核口径；两个名字并存以示口径不同，结课时自然收敛
- 教学层面三态全有归属：未考查 → 已考查 x/N 项；已考查未评价 → 已评价 y/x 项（教学进度小字 + 学情页覆盖副注）；已评价 → 学生口径达成率
- 知识点掌握率 = 掌握知识点 /（已评价知识点），最近一次老师确认评价（含退回）；技能达成率与知识点掌握率均配 ⓘ hover toast 显示算法
