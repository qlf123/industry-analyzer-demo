## 一、概述

### 1.1 业务背景

现有平台的权限只有「菜单」一个维度，无法支撑学校的分权管理：

| 现状 | 带来的问题 |
|---|---|
| 角色只勾菜单，有菜单即看到该菜单下的全量数据 | 管理工作无法下放：交给院系就等于交出全校数据 |
| 菜单只到「分组 / 页面」两层 | 做不到「能看不能删」「能编辑不能审核」 |
| 一个账号只能挂一个角色 | 「院系管理员 + 任课教师」这类常见身份无法表达 |
| 没有组织概念，专业、院系只是账号上的文字属性 | 多校区、多学院的学校无法按组织管理；跨院系授课没有地方配置 |
| 没有脱敏和审计 | 学生敏感信息全量可见，权限变化无法追溯 |

目标院校同时包括高职和中职，组织结构差异大（二级学院 / 系 / 教研室，或专业部 / 年级组），因此组织层级不能写死。

### 1.2 模块定位

| 本期解决 | 说明 |
|---|---|
| 组织 | 院校在后台自行录入组织树，层级和节点类型由院校维护 |
| 角色 | 重构为平台超级管理员、组织管理员、专业负责人、教师、班主任、辅导员、学生、四个部门模板、企业导师、自定义角色 |
| 范围 | 数据范围（组织节点 + 年级）、教学范围（专业 / 班级 / 课程）、指定班级、本专业、本基地 |
| 权限点 | 细化到页面内的操作 |
| 安全 | 字段脱敏、审计日志 |
| 协作 | 跨组织内容共享、校本资源库 |

### 1.3 在产品中的位置

```
管理端
├─ 数据概览
├─ 行业分析
├─ 教务基础数据
│   ├─ 专业管理          ← 改造：所属组织
│   ├─ 年级管理          ← 改造：已毕业状态
│   ├─ 班级管理          ← 改造：所属组织（随专业）
│   ├─ 学生信息          ← 新增
│   ├─ 教师档案          ← 新增（查看他人）
│   └─ 校本资源库管理    ← 新增
├─ 课程计划管理
├─ 账号与角色
│   ├─ 账号管理          ← 改造：多角色、范围
│   ├─ 角色管理          ← 改造：角色类型、操作级权限点
│   └─ 菜单管理          ← 改造：新增「操作」层
└─ 系统配置
    ├─ 组织管理          ← 新增
    ├─ 字典管理          ← 新增字典「组织类型」
    ├─ AI 配额           ← 新增
    └─ 审计日志          ← 新增

教师端
├─ 备课中心
│   ├─ 我的资源          ← 新增
│   ├─ 共享给我的        ← 新增
│   └─ 校本资源库        ← 新增

学生端
└─ 我的任务              ← 改造：已毕业只读

全部页面                  ← 接入范围过滤、按钮权限、脱敏、当前组织切换
```

## 二、全局规则

以下规则适用于本模块所有页面，评审与验收时逐条对照。

| # | 规则 | 说明 |
|---|---|---|
| G1 | **三步判定** | 每次访问依次判定：① 功能权限（有没有这个操作的权限点）→ ② 范围（数据在不在范围内）→ ③ 脱敏（字段怎么展示）。前两步不通过即拒绝 |
| G2 | **每条角色分配各自生效** | 一条分配的功能只在这条分配的范围内有效；用户的最终权限 = 各条分配「功能 × 范围」的并集。不能拿 A 分配的功能配 B 分配的范围 |
| G3 | **范围只向下覆盖** | 任何范围只覆盖所选节点及其全部下级，未选中的兄弟节点互不可见 |
| G4 | **授权不超过自身** | 不能给自己分配角色；授出的节点、年级、班级、教学范围不能超过授权人自身的范围 |
| G5 | **角色定义只归超管** | 角色定义、权限点配置、AI 配额配置仅限平台超级管理员 |
| G6 | **当前组织只是视图** | 「当前组织」只收窄列表，不改变权限，不影响菜单 |
| G7 | **脱敏处处一致** | 同一字段在列表、详情、导出中的脱敏结果相同 |
| G8 | **越权必拒必记** | 无权限的入口不展示；直接访问被拒绝，提示「您没有该操作的权限」，并记审计 |
| G9 | **关键操作可追溯** | 组织、角色、分配、教学范围、账号启停、配额、明文查看、共享发布等操作全部记审计，审计记录只读 |
| G10 | **停用即失效** | 账号停用时，其全部角色分配和教学范围同时失效 |

## 四、名词与口径

| 名词 | 口径 |
|---|---|
| 组织树 | 院校在后台录入的组织结构；根节点是院校，下面的层级和节点类型由院校定义，层级不设上限 |
| 组织类型 | 字典中维护的节点类型，如校区、学院、系；只用于展示、筛选和驾驶舱汇总，不参与权限判断 |
| 所属组织 | 专业、账号、基地等对象挂到的组织节点。专业、班级不进组织树 |
| 角色分配 | 一个用户的一条授权 = 角色 + 范围 + AI 配额。一个用户可以有多条 |
| 数据范围 | 一条分配勾选的一个或多个组织节点，每个节点可附加年级；可见数据 = 所选节点及其全部下级 |
| 年级筛选 | 节点上附加的年级，只作用于带年级属性的数据；不选年级 = 全部年级 |
| 教学范围 | 教师可授课 / 带班的专业、班级、课程；独立于数据范围；跨组织、跨专业为常态 |
| 本专业教师 | 教学范围包含本专业或本专业班级的教师 |
| 当前组织 | 页面顶部的视图过滤；默认「全部授权范围」 |
| 权限点 | 操作级的权限单位，按「模块 : 资源 : 动作」命名，如「专业建设 : 人培方案 : 审核发布」 |
| 部门条线 | 教务、学工、信息中心、督导，与组织树正交 |
| 内容共享 | 作者把一份内容开放给指定教师或指定组织的教师查看、复制；不改变任何人的范围 |
| 校本资源库 | 全校教师可查看、复制的内容，由组织管理员或教务发布 |

## 五、角色与范围

### 5.1 角色清单

| 角色 | 类型 | 所属端 | 默认范围 | 说明 |
|---|---|---|---|---|
| 平台超级管理员 | 内置 | 管理端 | 全组织 | 不受范围限制，操作全程审计；唯一可定义角色、配置权限点、配置 AI 配额的角色 |
| 组织管理员 | 预设 | 管理端 | 所挂组织节点及下级 | 替代原校级 / 校区 / 学部 / 院系管理员；挂根节点即全校统筹；可同时挂多个节点；权限统一，只按范围区分 |
| 专业负责人 | 预设 | 教师端 | 本专业 | 编辑本专业画像、人培方案和课程地图，无审核发布权 |
| 教师 | 预设 | 教师端 | 本人 + 教学范围 | 跨组织授课为常态 |
| 班主任 | 预设 | 管理端 | 指定班级（可多个） | 中职为主；管理本班学生 |
| 辅导员 | 预设 | 管理端 | 组织节点 + 年级，或指定班级 | 高职为主；管理所带年级 / 班级的学生 |
| 学生 | 预设 | 学生端 | 本人 | 仅本人数据 |
| 教务 | 部门模板 | 管理端 | 根节点 / 指定组织节点 | 排课、选课、成绩、教学运行，可跨组织调度 |
| 学工 | 部门模板 | 管理端 | 全校学生线 | 学籍、奖惩、资助，不触教研内容 |
| 督导 | 部门模板 | 管理端 | 全校教学质量 | 查看 + 听课评价，不参与内容审核 |
| 信息中心 | 部门模板 | 管理端 | 平台技术域 | 账号、系统、AI 引擎；不管理角色与权限策略，不碰业务内容 |
| 企业导师 | 自定义 | 教师端 | 本基地 | 基地课教学、实习评价；可在配额内使用 AI |
| 自定义角色 | 自定义 | 按配置 | 自由勾选 | 按权限点拼装 |

补充：

- 班主任、辅导员同时任课时，另行分配「教师」角色。
- 菜单 = 各条分配菜单的并集；跨端的多角色（如组织管理员 + 教师）可在管理端与教师端之间切换。

### 5.2 范围类型

| 范围类型 | 适用角色 | 可见数据 |
|---|---|---|
| 全部 | 平台超级管理员 | 全组织 |
| 所选组织节点及下级 | 组织管理员、教务（指定节点） | 所选节点及其全部下级；多个节点取并集 |
| 根节点 | 组织管理员（挂根节点）、教务、督导 | 全校 |
| 组织节点 + 年级 | 辅导员；组织管理员、教务、学工可附加年级 | 所选节点及下级中、所选年级的班级和学生 |
| 指定班级 | 班主任；辅导员（按班级授予时） | 所选班级的学生及其作业、考试、成绩、实习 |
| 本专业 | 专业负责人 | 该专业的课程、人培方案；本专业教师的档案 |
| 本基地 | 企业导师 | 该基地的实习学生、基地课与实习任务 |
| 本人 + 教学范围 | 教师 | 自己创建 / 归属的数据 + 教学范围内的课程、班级及学生 |
| 本人 | 学生 | 自己的数据 |
| 部门条线 | 学工 / 信息中心 / 督导 | 按条线全量 |

数据按类型取范围：

| 数据类型 | 包含 | 按什么判断 |
|---|---|---|
| 管理类 | 账号、专业画像、人培方案、审核、教师档案、基地 | 数据范围 |
| 教学类 | 课程、教案、作业、考试、成绩、所带学生 | 本人 + 教学范围 |

年级筛选只作用于带年级属性的数据：班级、学生及其作业、考试、成绩、实习；人培方案按「专业 + 年级」版本筛选。教师账号、教师档案、教材、基地、专业画像不受年级影响。

### 5.3 数据归属

| 数据 | 归属到 |
|---|---|
| 账号（教职工） | 账号的所属组织 |
| 账号（学生） | 班级 → 专业 → 专业的所属组织 |
| 专业画像、人培方案、课程地图 | 专业的所属组织 |
| 课程、教案、知识点、作业、考试、成绩 | 创建人本人 + 关联的专业 / 班级 |
| 教材 | 编写人本人 + 关联专业的所属组织 |
| 教师档案 | 教师账号的所属组织 |
| 校本 / 课程知识库 | 写入人的所属组织 |
| 基地、实习任务 | 基地的所属组织 |

### 5.4 授权约束

| 约束 | 规则 |
|---|---|
| 不能自授 | 任何人不能给自己分配角色 |
| 不超范围 | 授出的节点、年级、班级、教学范围不能超过授权人自身的范围 |
| 教学范围授予人 | 班级所在组织的组织管理员；教务可在自己的作用域内授予 |
| 审核发布 | 范围覆盖该内容的任一组织管理员都可以审核发布 |
| 角色定义 | 仅平台超级管理员 |
| 有效期 | 教学范围长期有效，由授予人或其上级组织的组织管理员撤销 |

## 六、全局：当前组织切换

位置：管理端、教师端页面顶部。

| 规则 | 说明 |
|---|---|
| 显示条件 | 至少有一条带组织节点的角色分配时显示；教师、班主任、学生、企业导师等没有组织节点范围的身份不显示 |
| 可选项 | 「全部授权范围」+ 授权范围内的组织节点及其下级，树形选择；一人多角色时取所有带组织节点的分配的并集；停用节点不出现 |
| 默认值 | 「全部授权范围」。登录后、切换角色后恢复为默认值；同一次登录内跨页面保留选择 |
| 作用 | 选中某节点时，数据列表只显示该节点及其下级的数据；权限不变（G6） |
| 不受影响 | 菜单；年级筛选；教学范围内的数据 |
| 新增数据 | 选中单个节点时，新增数据的「所属组织」默认填为当前组织，可在授权范围内修改 |
| 提示 | 列表顶部显示「当前组织：xxx（仅显示该组织及下级的数据）」 |
| 空状态 | 因当前组织收窄导致列表为空时，提示「当前组织下暂无数据，可切换为全部授权范围查看」 |
| 审计 | 切换不记审计 |

## 七、系统配置

### 7.1 组织管理（新增）

**页面结构**

| 区域 | 规则 |
|---|---|
| 左侧组织树 | 可展开 / 收起；按名称搜索，命中节点高亮并自动展开上级；停用节点灰显，带「已停用」标签 |
| 右侧详情 | 节点信息、下级节点数、挂载专业数、所属账号数，以及操作按钮 |
| 组织管理员视角 | 本节点及其上级只读（灰色、无操作按钮），只能操作本节点的下级 |

**节点字段**

| 字段 | 必填 | 规则 |
|---|---|---|
| 节点名称 | 是 | 1–30 字；同一上级下不可重名 |
| 节点编码 | 是 | 1–30 位字母、数字、短横线；全局唯一；保存后不可修改 |
| 组织类型 | 是 | 从字典「组织类型」中选择，仅启用的类型可选 |
| 上级节点 | 是 | 根节点以外必选；只能选启用中的节点；组织管理员只能选本节点或其下级 |
| 排序 | 否 | 整数，同级内升序，默认 0 |
| 状态 | 是 | 启用 / 停用，默认启用 |
| 说明 | 否 | 0–200 字 |

**操作**

| 操作 | 谁能做 | 规则与提示 |
|---|---|---|
| 新增下级 | 超管：任意节点；组织管理员：本节点及其下级 | 弹窗录入字段；层级不设上限 |
| 编辑 | 超管：根节点以外任意节点；组织管理员：本节点的下级 | 根节点名称取自「院校基础信息」，此处只读 |
| 移动 | 同「编辑」 | 选择新的上级节点，不能选自身及其下级。确认框：「移动后，其下级节点、挂载专业和相关数据将一起移动，引用它的角色范围按新位置生效。」 |
| 停用 / 启用 | 同「编辑」 | 停用确认框：「停用后，该节点不能再被选为数据范围或所属组织；已有授权保持有效。」下级节点不随之停用 |
| 删除 | 同「编辑」 | 有子节点、挂载专业、所属账号或被角色范围引用时不能删除，弹窗列出阻塞对象及数量：「该节点下仍有：子节点 2 个、专业 1 个……请先迁移后再删除。」 |

根节点唯一，不可删除、移动、停用。所有操作记审计。

停用节点在角色分配中显示为「节点已停用」标签，授权仍然有效。

### 7.2 字典管理 · 组织类型（新增字典）

| 规则 | 说明 |
|---|---|
| 字段 | 类型名称（必填，1–20 字，不可重名）、排序、状态、说明 |

| 情况 | 提示文案 |

## 十三、数据迁移与上线

| 序 | 事项 |
|---|---|
| 1 | 在「组织管理」录入组织树，在字典中定义组织类型 |

## 十五、技术评估项（由开发评估）

以下事项涉及技术实现，产品不做决定。评估时以本 PRD 的规则与验收为准，结论回填本节。

| # | 事项 | 现状 | 产品侧要求 |
|---|---|---|---|
| 1 | 组织树的存储与「节点及下级」的范围计算 | 无组织结构 | 层级不设上限；移动后范围立即按新位置生效；列表体验不因层级加深而明显变慢 |
| 2 | 操作级权限点的承载方式 | 菜单只有分组和页面两层 | 前后端使用同一套权限点；菜单管理可维护操作层 |
| 3 | 平台超级管理员的放行方式 | 管理员不走菜单配置，直接全部可见 | 超管操作可审计；不再依赖写死的放行 |
| 4 | 字段脱敏的执行位置 | 无脱敏 | 页面、详情、导出三处结果一致 |
| 5 | 审计记录的存储与查询 | 无审计 | 只读、不可删改；可按时间、操作人、组织筛选 |
| 6 | AI 配额的计数与重置 | 无配额 | 多角色取最高值；每日 0 点重置 |
| 7 | 多角色、年级筛选下的范围判定 | 单角色 | 结果符合第二、五章；不出现跨分配组合导致的越权 |

## 十六、验收用例

### 16.1 组织

- [ ] 录入「院校 → 学院」两层与「院校 → 校区 → 学院 → 系 → 教研室」五层，两种结构下范围判定都正确
- [ ] 组织管理员挂在某学院时，组织树中只能操作该学院的下级节点，本节点及上级无操作按钮
- [ ] 删除挂有专业的节点 → 被拒绝，并列出阻塞对象
- [ ] 停用某节点后分配角色 → 该节点不可选；已有授权显示「节点已停用」
- [ ] 删除被节点引用的组织类型 → 提示「该类型已被 N 个组织节点使用，不能删除。」

### 16.2 范围与多角色

- [ ] 组织管理员挂学院 A，查看账号列表 → 只出现学院 A 及其下级的账号
- [ ] 组织管理员同时挂学院 A、学院 B → 两个学院的数据都可见，其他学院不可见
- [ ] 学院 A 组织管理员 + 学院 B 1 班教学范围，进入学院 B 的审核页 → 看不到审核按钮；直接请求被拒绝并记审计
- [ ] 教师查看学院 B 1 班、2 班作业（教学范围只有 1 班）→ 1 班可见，2 班不可见
- [ ] 辅导员范围为「学院 A + 2026 级」，查看学生信息 → 只出现学院 A 下 2026 级的学生
- [ ] 组织管理员范围为「学院 A + 2026 级」，查看教师档案 → 显示学院 A 全部教师档案，不受年级影响
- [ ] 班主任查看本班与其他班学生信息 → 本班可见（手机号、住址全量，身份证脱敏），其他班不可见
- [ ] 企业导师查看实习学生 → 只看到本基地学生；可在配额内使用 AI

### 16.3 授权与角色

- [ ] 组织管理员给自己分配角色 → 被拒绝，提示「不能给自己分配角色。」
- [ ] 组织管理员给他人授予超出自身范围的节点 → 被拒绝，提示「「xxx」不在您的授权范围内，不能授予。」
- [ ] 学院 A 的组织管理员给老师授予学院 B 的班级 → 被拒绝，提示联系该班级所在组织的管理员
- [ ] 督导进入课程、教材、人培的审核页 → 无审核按钮；可在教师档案页提交评价
- [ ] 信息中心查找角色管理、权限点配置 → 无入口；账号的新建、启停、重置密码可用
- [ ] 停用某教师账号 → 全部角色分配和教学范围失效，所有操作被拒绝；分配卡片显示「账号已停用，分配已失效」
- [ ] 预设角色修改权限点后点「恢复默认」→ 恢复为第十一章矩阵的权限

### 16.4 当前组织

- [ ] 组织管理员挂学院 A + 学院 B，当前组织切到学院 A → 只显示学院 A 的数据，顶部提示「当前组织：学院 A（仅显示该组织及下级的数据）」
- [ ] 切回「全部授权范围」→ 两个学院都可见；菜单全程不变
- [ ] 教师、班主任、学生、企业导师登录 → 不显示当前组织下拉
- [ ] 当前组织为单个节点时新增账号 → 所属组织默认填为该节点，可修改

### 16.5 脱敏与审计

- [ ] 教务查看作用域内学生成绩 → 成绩明文；身份证、住址不可见；手机号脱敏
- [ ] 同一学生信息分别在列表、详情、导出中查看 → 脱敏结果一致
- [ ] 学工未授权时身份证为脱敏；超管授予「身份证明文」后显示「查看明文」，点击后全量，且记审计
- [ ] 学生查看本人信息 → 手机号、身份证、住址全量
- [ ] 第 7.4 节列出的每类操作执行一次 → 审计日志中均有记录，且不能修改、删除

### 16.6 毕业生与 AI

- [ ] 年级设为「已毕业」→ 该年级学生状态变为「已毕业」；该年级班级不再出现在教学范围可选班级中
- [ ] 已毕业学生登录 → 只能查看本人历史数据，无提交按钮；教师对该年级只读
- [ ] 教师当日 AI 配额用完后再次调用 → 提示「今日配额已用完，明日 0 点恢复」，次日恢复

### 16.7 内容共享

- [ ] 教师把课件共享给学院 2 节点 → 学院 2 的教师可查看、复制；学院 3 的教师看不到
- [ ] 接收人修改复制出的副本 → 作者的原件不变
- [ ] 作者推荐到校本资源库 → 发布前全校不可见；组织管理员发布后全校教师可查看、复制
- [ ] 组织管理员「不发布」时不填原因 → 无法提交；填写后作者可见原因
- [ ] 作者撤回共享 → 接收人看不到原件，已复制的副本仍在
- [ ] 学情分析类资源 → 没有「共享」「推荐」按钮
