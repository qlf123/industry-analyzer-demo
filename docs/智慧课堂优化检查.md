# 智慧课堂（教师端）优化检查

> 检查对象：`teacher-tasks.html`（全 1929 行）+ 工作台回流链路（workbench.html）
> 检查目标：老师能否在智慧课堂里顺畅地干完「备课 → 发布 → 评价 → 学情 → 补训」所有事
> 日期：2026-11-12（仅检查，未改动代码）

## 一句话结论

**主闭环已经通且顺（备课带入-发布确认-评价确认-学情补训-改进建议全链路可走、待办聚合和资源复用提示是亮点），剩余断点集中在「发布后不可改、评价不能连续批、知识点配置指路落空」三个 P0 上。**

## 已做得好的（不需要动）

| 能力 | 说明 |
|---|---|
| 待办聚合 | 首页把评价/发布/反馈/负责人建议聚成待办，且按紧迫度排序 |
| 备课带入回流 | 课次「去备课」带 payload 进工作台，生成后资源包自动关联回课次并给「去智慧课堂发布 ›」直达链接 |
| 资源复用提示 | 按课程进度算下一个任务，资源行提示「＋ 复用到 某班 · 第N次课」 |
| 发布时确认口径 | 考查技能默认全选可取消 + 知识体系补选 + 知识点独立勾选 + 判定依据可改 + 发布即快照 |
| 冲突提示不拦截 | 自建课次与排课/他人课次重叠时确认后仍可创建，课表重叠显示 |
| 补训/辅导闭环 | 学情未达成 → 一键发起补训（自动关联含该技能的资源、预选学生） |

## 可优化点（按优先级）

### P0 · 流程断点（老师会卡住或走错路）

| # | 问题 | 证据 | 建议 |
|---|---|---|---|
| 1 | **发布后完全不可修改任务**：不能改任务说明、截止时间，不能撤回重发；发布错了只能「追加资源」，任务层面的错误无解 | addResModal 注释「已发布的内容不能修改或撤回」（L1296）；courseForm locked 时时间禁改 | 增加「有限撤回」：尚无人提交时可撤回重发（清空 submissions、记审计）；已有人提交时允许只改「截止时间 / 任务说明」这类不影响口径的字段 |
| 2 | **知识点配置指路落空**：学情页提示「可在备课资源里为技能配置知识点」，但资源编辑表单只有任务与技能勾选，没有知识点配置入口——提示指向一条不存在的路 | 提示见 L1051；resForm 字段只有 name/course/files/任务与技能（L855-900） | 二选一：①在 resForm 勾选技能后联动展示该技能下知识点供老师勾选（推荐，与发布口径一致）；②改掉学情提示文案，指到发布配置 |
| 3 | **评价不能连续批**：评完一条抽屉关闭回列表，要点下一条；「采用 AI 初评」也只能一条一条点。30 份作业 = 30 次进出抽屉 | evalDrawer finish 后 d.close()+after()（L1741）；foot 无「下一条」 | ①抽屉加「保存并评下一条」（按待评价顺序自动跳）；②列表/抽屉支持勾选多条「批量采用 AI 初评」 |

### P1 · 高频动作提效

| # | 问题 | 证据 | 建议 |

| 4 | **未提交学生无法提醒**：截止时间过了，学情里能看到「未提交」人数，但没有一键催交动作 | statView 只列「N 个技能未提交」统计 | 课次详情「情景任务评价」页加「提醒未交学生」按钮（学生端消息 +1 条） |

## 建议节奏

1. **先修 P0-2**（知识点指路落空）：改动最小，只动 resForm，口径与发布页对齐
2. **再做 P0-3**（连续评价 + 批量采用 AI）：老师日常最高频动作，收益最大
3. **P0-1（有限撤回）单独过一版规则**：涉及「发布不可变」的既定口径（2026-11-10 定），需要先确认撤回边界（无人提交可撤回？提交后允许改哪些字段？）
