编辑说明

＋添加模块：新增一个图谱域（命名、选色）。
＋添加节点：选域、填名称。
＋添加关系：先点起点，再点终点，填关系名与类别。
移动模块：拖动域的虚线框整块挪位置；双击虚线框/标题（或点图例✎）编辑模块。
概念属性：点节点 → 详情卡片里「＋属性」新增，点属性行✎编辑/删除。
删除关系：点击关系线 → 弹窗里「删除这条关系」。
删除节点：点击节点 → 卡片里「删除」（相关关系一并删除）。
改动自动保存本机；「恢复默认数据」回到初始模型。
