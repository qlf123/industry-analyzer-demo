## 2. 数据口径（落地实现）

- **关联写在哪**：`edu.courses[]` 上 `ks`（课程节点 id 或 `GKS-<体系id>`）/ `ksName` / `ksVia`（专业知识体系 | 图谱中心 | 管理端补选）/ `ksFrom`（来源体系 id）/ `ksBy` / `ksAt`。课程知识体系一律 `GKS-` 前缀，据此区分「课程知识体系只对应一门课」与「专业体系课程节点可多课关联」两条规则。
- **预置关联**：演示数据里导游专业课程预置关联在「旅游类-导游」（KS013）的课程节点上，首次进入知识体系页只补一次关联（`KS_DATA_MAP`），之后完全以用户操作为准。
- **反哺链路**：`localStorage graphSuggest.v1`，状态机 待审核 → 已采纳（待发布）→ 已发布 / 已退回（重提替换）。
- **回落规则**：课程知识体系解除后 `fallbackLink()` 自动改用所属专业体系同名课程节点，没有则置空（4.3 ✓）。
