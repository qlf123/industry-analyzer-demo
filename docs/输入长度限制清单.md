# 新增 / 编辑表单 · 输入字数限制清单

盘点日期：2026-11-18
范围：全项目所有「新增 / 编辑 / 提交」类表单中的用户可输入字段（不含列表筛选、搜索、查看类控件）

---

## 0. 一句话规则

**所有输入框只显示「最多 N 个字」，1 个汉字、1 个字母、1 个数字、1 个标点都算 1 个字。**
不再区分中文、英文、全角、半角——学校工作人员不需要理解这些差别。

页面上的提示统一写成：

> 最多 60 个字（已输入 12 个字）

超长内容在列表 / 卡片里由样式截断（省略号 + 悬停看全名），不靠限制输入解决排版。

## 4. 实现建议

1. **前端只认「字数」**：所有 `maxlength` 直接用档位值（60 / 100 / 500 / 2000 / 3000）。
2. **提示统一**：输入框下方写「最多 60 个字」，长文本（≥500）显示「已输入 12 / 500 字」。
3. **不解释中英文差异**：计数按字符数，1 个汉字、1 个字母、1 个数字、1 个标点都算 1 个字；页面上不出现「字符位」「全角」「字节」等说法。
4. **固定格式字段单独校验**：手机号 11 位、身份证 18 位、邮箱含 @，不要靠字数限制。
5. **编码类**：字数 60，同时限制为字母 / 数字 / 下划线，避免中文混入。
6. **数字 / 日期 / 文件**：不用 maxlength，数字用 min / max，文件用类型 + 大小。
7. **展示与输入分开**：列表 / 卡片 / 时间线用 CSS 截断 + 悬停看全名，不要为了排版收紧输入上限。
8. **后端再校验一次**：原型没有后端；正式开发在接口层按同一套字数校验。

### 给开发的计数说明（不出现在页面上）

- `maxlength` 按字符计：1 个汉字、1 个英文字母、1 个数字、1 个标点都是 1；emoji 和生僻字可能占 2，属正常现象。
- 用户只看到「字」，不需要知道 emoji 占 2；学生作答里如果出现 emoji，计数会跳 2，可接受。
- 不再做「汉字算 2 列」的宽度校验，也不在前端区分中英文。
