# 新增 / 编辑表单 · 输入长度限制清单（建议值）

盘点日期：2026-11-17
范围：全项目所有「新增 / 编辑 / 提交」类表单中的用户可输入字段（不含列表筛选、搜索、查看类控件）

---

## 0. 现状结论

1. **普通文本框（`input type=text`）基本都没有限制**。根因在 `js/teacher-kit.js`：
   - `fieldHTML()` 的 text 分支（709 行）不渲染 `maxlength`，也不读字段定义里的 `max`；
   - 只有 textarea 分支（705 行）有默认值 `maxlength="500"`（`f.max || 500`）。
2. **并非「全都没有」**：已有 15 个文件、约 37 处设置了 maxlength，集中在系统配置类页面（`role` / `menu` / `dict` / `college` / `sysconf` / `kmap` / `suggest-review` 等），以及学生作答（3000）、课程反馈（500）、AI 评价要求（500）。
3. **teacher-file.html 的 27 个 textarea 实际都受 500 限制**，75 个文本框无限制。
4. **风险最大的是**：教务基础数据、教师端课次/任务/资源、图谱节点与能力项、账号管理、教师档案——这些业务主链路的文本框全部没有上限。

## 1. 统一档位（8 类）

原则：**同一类字段只用一套规则**；名称类按「显示宽度」算，说明类按「字符数」算，非文本类不设 maxlength。

| 档位 | 规则 | 中英折算 | 对应字段 |
|---|---|---|---|
| **A 编码 / 标识** | 50 个 ASCII 字符 | 不允许汉字；英文/数字/符号各 1 | 专业、年级、班级、课程、组织、角色编码；学号、工号；证书 / 项目 / 立项 / 专利 / 申请 / 授权编号；ISSN / ISBN；卷、期、页码；登录账号、密码、模型名。固定格式：手机号 20、身份证 18 |
| **B 短名** | 40 列 | 20 汉字 / 40 英文 | 人名、联系人、负责人、民族、籍贯、职称名称、岗位 / 职务、部门、说话人、建议考核方式、评估方式、映射关系、组织类型名、院校简称、规划周期、论文级别。菜单 / 目录名沿用现有 12 / 10（导航宽度约束） |
| **C 名称** | 80 列 | 40 汉字 / 80 英文 | 专业、年级、班级、课程、知识体系、图谱、知识库、节点、知识点、课次、资源、任务、实训资源、子图、组织、院系、教学组织、专业方向、研究方向、领域；单位 / 机构名、毕业院校、工作单位；证书名称、奖项名称、荣誉名称、文档名称、专利权人、技术领域 |
| **D 长名** | 160 列 | 80 汉字 / 160 英文 | 项目名称、论文题目、导师 / 论文题目、期刊 / 会议名称、院校地址、活动名称、报告题目、服务项目名称、贡献事迹标题、关联项目 / 成果、获奖作品 |
| **E 说明** | 500 字 | 中英均按字符，1 汉字 = 1 | 专业 / 班级 / 课程 / 角色 / 组织说明；备注；评语；判定依据；审核意见；退回 / 驳回 / 停用原因；提交理由；节点说明；知识点核心内容 / 定义；文档说明；方案说明；处理说明；热词；画面描述；活动描述；获奖描述；关键指标；评审情况说明；续期说明；DOI / CN；接口地址；API Key；AI 评价要求（PRD 定 500）；评价标准三档 |
| **F 长文本** | 2000 字 | 中英均按字符 | 任务说明、改进建议、AI 备课需求、个人简介、发展方向、所需支持、岗位职责、工作业绩、项目简介、阶段成果、培训内容、收获反思、进修成果 / 描述、论文摘要、专利摘要 / 转化、服务成果 / 描述、事迹详细描述、图中文字、院校简介 |
| **G 超长文本** | 3000 字 | 中英均按字符 | 学生提交的文字内容（既定口径）。知识库分段正文不硬限，仅提示 5000 |
| **H 非文本（本次新增）** | 不用 maxlength | 数字用 min / max；日期 / 时间用格式；枚举用取值范围；文件用类型 + 大小 | 排序、人数、工位、经费、学时、天数、阈值、分段长度；日期、datetime、time；select / searchselect / chips / switch；文件上传；音视频起止 mm:ss |

> 判断口径：**名称 / 标题 → 按宽度（B/C/D）；说明 / 正文 → 按字符（E/F/G）；编码 → ASCII（A）；其余 → H。**
> 除 A 以外，B–G 都允许中英混排，按上表折算。

## 4. 实现建议

1. **先改公共渲染器**：`js/teacher-kit.js:709` 的 text 分支增加 `maxlength`，读取 `f.max`；textarea 保持 `f.max || 500`。默认值只做兜底，业务表单显式传档位值。
2. **名称类按宽度校验**：B / C / D 三档传「列数」，用 `maxlength` 做兜底（值 = 列数），`oninput` 用 `charWidth()` 校验并回退到上一次合法值。
3. **说明类按字符校验**：E / F / G 三档直接传字符数，`maxlength` 即可；`max ≥ 1000` 时加「N / max」计数。
4. **A 档校验字符集**：`[A-Za-z0-9_\-./@+]`，手机号、身份证用固定格式正则，不靠 maxlength。
5. **H 档用 `min` / `max` / `accept` / `size`**：数字、日期、文件不要套 maxlength。
6. **前端限制不等于校验**：原型无后端；正式开发必须在接口层再做一次长度与字符集校验。
7. **展示与输入分开**：`maxlength` 只管输入；列表 / 卡片 / 时间线仍需 CSS 截断 + `title`。

## 6. 计数规则（中文 / 英文 / 混排）

### 6.1 两种计数方式

| 方式 | 规则 | 用于 |
|---|---|---|
| 字符数 | 1 个汉字 = 1，1 个英文字母 = 1，空格 / 标点 = 1，emoji = 2（UTF-16 码元） | E / F / G 说明类、A 编码类 |
| 显示宽度 | 汉字 / 全角 = 2 列，英文 / 数字 / 半角 = 1 列 | B / C / D 名称类 |

`maxlength` 永远按字符数计；宽度校验必须用 JS。

### 6.2 混排公式

```
宽度 = 2 × 汉字数 + 1 × 英文/数字/半角符号数 + 1 × 半角空格数
```

| 文本 | 计算 | 宽度 |
|---|---|---|
| 导游服务 | 4 × 2 | 8 |
| Tour Guide Service | 17 × 1 | 17 |
| 导游服务 Tour Guide Service | 8 + 1 + 17 | 26 |
| 智慧课堂 AIGC 平台 | 8 + 1 + 4 + 1 + 4 | 18 |
| 全角 ＡＢＣ | 3 × 2 | 6 |

**换算**：C 档 80 列 = 40 汉字 = 80 英文 = 20 汉字 + 40 英文。

### 6.3 实现

```js
function charWidth(s) {
  let w = 0;
  for (const ch of s) {                       // for...of 按码点，不拆 emoji
    const cp = ch.codePointAt(0);
    const wide = cp === 0x3000 ||
      /[\u1100-\u115F\u2E80-\u303E\u3041-\u33FF\u3400-\u4DBF\u4E00-\u9FFF\uAC00-\uD7A3\uF900-\uFAFF\uFE30-\uFE6F\uFF00-\uFF60\uFFE0-\uFFE6]/.test(ch) ||
      cp >= 0x1F300;
    w += wide ? 2 : 1;
  }
  return w;
}
```

- 超限时回退到上一次合法值，不要 `slice` 截断（会截断 emoji / 组合字符）。
- 精确宽度用 `east-asian-width` 或 Unicode EastAsianWidth 数据。
- 计数显示「42 / 80」，不要显示「21 / 40 字」。

### 6.4 边界

| 内容 | 宽度 |
|---|---|
| 半角空格 / Tab | 1（Tab 也可按 4，需与展示一致） |
| 全角空格 U+3000 | 2 |
| 全角字母数字（ＡＢＣ１２３） | 2 |
| 全角中文标点（，。！？） | 2 |
| 半角英文标点 | 1 |
| 单个 emoji | 2 |
| ZWJ 组合 emoji（👨‍👩‍👧） | 1 个字形，宽度 2 |
| 生僻字（扩展 B 区 𠮷） | 2 |
| 换行 | 宽度校验时忽略 |

### 6.5 PRD 写法

> 最多 80 个字符位（1 个汉字 / 全角符号占 2 位，1 个英文 / 半角符号占 1 位）。

不要只写「最多 80 字」，也不要写「80 字节」。
